```python
embeddings = VoyageAIEmbeddings(
    voyage_api_key="[ Your Voyage API key ]", model="voyage-law-2"

```

```python
documents = [
```

## A minimalist retrieval system

The main feature of the embeddings is that the cosine similarity between two embeddings captures the semantic relatedness of the corresponding original passages. This allows us to use the embeddings to do semantic retrieval / search.

 We can find a few closest embeddings in the documents embeddings based on the cosine similarity, and retrieve the corresponding document using the `KNNRetriever` class from LangChain.

<LangchainCommunityUnmaintained />

```python
from langchain_community.retrievers import KNNRetriever

retriever = KNNRetriever.from_texts(documents, embeddings)

# retrieve the most relevant documents
result = retriever.invoke(query)
top1_retrieved_doc = result[0].page_content  # return the top1 retrieved result

print(top1_retrieved_doc)
```

It formats the prompt template using the input key values provided (and also memory key values, if available), passes the formatted string to LLM and returns the LLM output.

## Contextualized chunk embeddings

The contextual models (`voyage-context-4` and `voyage-context-3`) embed each chunk with awareness of the surrounding document, improving retrieval quality for long, chunked documents. Call the `contextualized_embed` API on the `voyageai` client directly.

To let VoyageAI by MongoDB chunk each document server-side, pass a flat `list[str]` of documents as `inputs`, set `input_type="document"`, and enable `enable_auto_chunking=True`. When auto chunking is enabled, `chunk_size` sets the target chunk size in tokens (up to a maximum of 32000):

```python
import voyageai

vo = voyageai.Client()  # reads the VOYAGE_API_KEY environment variable

documents = [
    "Caching embeddings enables the storage or temporary caching of embeddings, eliminating the necessity to recompute them each time.",
    "A Runnable represents a generic unit of work that can be invoked, batched, streamed, and/or transformed.",
]

result = vo.contextualized_embed(
    inputs=documents,
    model="voyage-context-4",
    input_type="document",
    enable_auto_chunking=True,
    chunk_size=32000,
)

# One entry per input document; each holds the per-chunk embeddings.
document_embeddings = [chunk_embeddings for r in result.results for chunk_embeddings in r.embeddings]
```
